# MediCare Backend (FastAPI)

REST API for the MediCare medication reminder system. See the [root README](../README.md) for the full project overview, architecture diagram, and demo credentials — this file covers just the backend.

## Quick start (SQLite, zero config)

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000
```

The API is now at `http://localhost:8000`, interactive docs at `http://localhost:8000/docs`. A SQLite file `medicare.db` is created automatically, and a demo account is seeded (see root README for credentials) because `.env.example` ships with `ENABLE_DEMO_SEED=true`.

## Switching to PostgreSQL

1. Create a database and user (or just run `docker-compose up db` from the project root).
2. In `.env`, set:
   ```
   DATABASE_URL=postgresql+psycopg2://medicare_user:medicare_pass@localhost:5432/medicare_db
   ```
3. Restart the server — tables are created automatically on startup.

## Project layout

```
app/
├── main.py           FastAPI app, middleware, error handlers, startup/shutdown
├── config.py         Settings loaded from environment variables (.env)
├── database.py       SQLAlchemy engine/session + init_db()
├── models/           SQLAlchemy ORM models (one file: models.py)
├── schemas/          Pydantic request/response schemas, one file per resource
├── routers/          FastAPI route handlers, one file per resource
├── services/         Business logic used by routers (kept thin routers, fat services)
├── auth/             Password hashing, JWT issuing/verification, get_current_user
├── scheduler/        Background APScheduler job that drives reminders
└── utils/            Small shared helpers (date math, pagination, rate limiting)
```

## Running the reminder scheduler

It starts automatically with the API (see `main.py`'s `lifespan`). Every `REMINDER_CHECK_INTERVAL_SECONDS` (default 60s) it:
1. Generates today's/tomorrow's pending dose logs for every active medication.
2. Creates an in-app "reminder" notification for any dose due within `UPCOMING_NOTICE_MINUTES`.
3. Marks any dose more than `MISSED_DOSE_GRACE_MINUTES` overdue as **missed** and notifies.

Tune these in `.env`.

## Re-seeding demo data on demand

```bash
python seed.py
```

## Running tests

This build ships without a test suite (out of scope for the timeline of this project), but the service layer (`app/services/`) and `app/utils/helpers.py` are written dependency-free/pure where possible specifically so they're easy to unit test with `pytest` if you extend this project.

## API documentation

Full interactive documentation (Swagger UI) is auto-generated by FastAPI at `/docs` whenever the server is running, and the raw OpenAPI schema at `/openapi.json`. See the root README for a plain-text summary of every endpoint.
